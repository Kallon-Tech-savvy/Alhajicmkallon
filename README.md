# Alhaji Kallon | The Future Builder

A high-end, world-class personal brand platform.

## Packages Used

### Dependencies
- next@16.2.9
- react@19.2.4
- react-dom@19.2.4
- framer-motion
- lucide-react
- clsx
- tailwind-merge

### Dev Dependencies
- tailwindcss@4
- @tailwindcss/postcss@4
- typescript
- @types/node
- @types/react
- @types/react-dom
- eslint
- eslint-config-next@16.2.9

## Installation Commands

```bash
# Install core dependencies
npm install next@16.2.9 react@19.2.4 react-dom@19.2.4 framer-motion lucide-react clsx tailwind-merge

# Install dev dependencies
npm install -D tailwindcss@4 @tailwindcss/postcss@4 typescript @types/node @types/react @types/react-dom eslint eslint-config-next@16.2.9
```
